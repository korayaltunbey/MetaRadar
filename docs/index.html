Screenshots

Permissions

Three permissions for a focused tool.

activeTab
Temporary access to the active page after the user invokes MetaRadar.
scripting
Runs MetaRadar’s packaged read-only page reader.
storage
Stores only the selected theme preference locally.

Local Installation

  1. Download or clone the GitHub repository.
  2. Open chrome://extensions.
  3. Enable Developer mode.
  4. Select Load unpacked.
  5. Choose the project root containing manifest.json.
